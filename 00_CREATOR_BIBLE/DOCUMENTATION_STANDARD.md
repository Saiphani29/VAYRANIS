# Documentation Standard

## Note Format

- Start with a short title.
- Use simple headings.
- Keep paragraphs concise.
- Add links to related notes when useful.

## File Naming

- Use uppercase with underscores for key documents.
- Use descriptive names.
- Keep names stable once a note is established.

## Linking

- Link related ideas with Obsidian wiki links.
- Add an index entry when a note becomes important.
