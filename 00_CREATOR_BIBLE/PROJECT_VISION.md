# Project Vision

VAYRANIS is the central world bible for a coherent fictional setting.

The goal is to keep lore, visuals, characters, and story aligned under one organized system so the project can grow without losing consistency.

## Goals

- Build a stable canon reference for the world.
- Keep notes easy to browse in Obsidian.
- Separate high-level world rules from detailed lore.
- Make it simple to add new ideas without breaking continuity.

## Principles

- Clarity first.
- Canon should be easy to find.
- Related notes should be linked.
- New content should extend the system, not replace it.
