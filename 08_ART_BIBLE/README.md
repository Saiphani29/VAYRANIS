# VAYRANIS ART BIBLE

## Purpose

The Art Bible is the visual foundation of VAYRANIS. It stores approved design systems, visual rules, evolution paths, drafts, and references.

## Main Sections

- Shape Language
- Royal Design
- Clothing Evolution
- Architecture
- Tools and Weapons
- Character Visual Design
- Visual References

## Design Philosophy

Every design follows:

Nature / Observation → Function → Evolution → Craft → Culture → Symbol

A design is not only an appearance. It must explain why it exists, how it developed, and how it connects with the world.

## Documentation Template

Each design document should contain:

1. Purpose
2. Origin
3. Evolution
4. Function
5. Design Language
6. Cultural Meaning
7. Connections
8. Visual References
9. Open Questions
10. Status

## Status System

🟢 Canon - approved foundation

🟡 Draft - developing concept

🔴 Archive - old experiment or rejected direction
