# Roadmap

This roadmap shows the order in which the vault should grow.

## Phase 1

- Set up the vault structure so the project is easy to navigate.
- Establish the Creator Bible so the project has clear rules.
- Create the core indexes and standards so future notes stay consistent.

## Phase 2

- Define the world foundation so the setting has a stable base.
- Add geography, cosmology, and natural rules so the world starts to feel real.

## Phase 3

- Expand civilization, culture, and history so people and events give the world depth.

## Phase 4

- Add characters, story arcs, art direction, and reference material so the project can support stories and visuals.
