# World Design Philosophy

VAYRANIS should be built from the inside out.

That means defining the rules of the world first, then letting culture, conflict, art, and story grow naturally from those rules. The setting should feel like it could exist on its own terms, not like a random collection of ideas.

## Approach

- Start with foundations so the world has rules before details are added.
- Add detail in layers so each note builds on the one before it.
- Keep each layer linked to the next so the vault remains navigable.
- Favor internal logic over random additions unless a deliberate contradiction is part of the story.
