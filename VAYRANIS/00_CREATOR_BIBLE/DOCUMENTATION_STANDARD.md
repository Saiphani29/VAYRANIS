# Documentation Standard

This note explains how to write entries so they stay useful over time.

## Note Format

- Start with a short title so the subject is obvious.
- Use simple headings so the page can be scanned quickly.
- Keep paragraphs concise so the main idea stays visible.
- Add links to related notes when useful, especially when a file depends on another one.

## File Naming

- Use uppercase with underscores for key documents so they stand out as canon files.
- Use descriptive names so a reader can guess the topic before opening the file.
- Keep names stable once a note is established, unless a rename clearly improves the system.

## Linking

- Link related ideas with Obsidian wiki links.
- Add an index entry when a note becomes important enough that it should be discoverable from the front page.
