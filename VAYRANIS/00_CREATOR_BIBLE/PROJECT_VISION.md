# Project Vision

VAYRANIS is the central world bible for a coherent fictional setting. It exists so the project can grow without losing its identity, canon, or visual logic.

The goal is to keep lore, visuals, characters, and story aligned under one organized system so every new idea can be checked against the same source of truth.

## Goals

- Build a stable canon reference for the world so later notes have a reliable base.
- Keep notes easy to browse in Obsidian so the vault remains usable as it grows.
- Separate high-level world rules from detailed lore so each layer stays readable.
- Make it simple to add new ideas without breaking continuity or duplicating decisions.

## Principles

- Clarity first, because a world bible only works if it is easy to understand.
- Canon should be easy to find, because hidden rules create confusion later.
- Related notes should be linked, so the vault behaves like a connected system instead of isolated pages.
- New content should extend the system, not replace it, unless the project intentionally revises canon.
