# Naming Conventions

These conventions keep the vault easy to sort, search, and expand.

## Folders

- Use numeric prefixes for major sections so the broad structure stays in a predictable order.
- Keep folder names broad and easy to understand.

## Files

- Use uppercase file names for primary canon documents so they are visually distinct from casual notes.
- Use clear names that describe the content directly.
- Prefer one topic per file when possible.

## Examples

- `PROJECT_VISION.md`
- `WORLD_DESIGN_PHILOSOPHY.md`
- `HISTORY_OVERVIEW.md`
