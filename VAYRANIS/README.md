# VAYRANIS

VAYRANIS is the master vault for the project. It is meant to hold the world bible, creator bible, art bible, story notes, and future reference material in one structured place.

This repository is set up to work as an Obsidian vault, so every folder can hold linked Markdown notes that are easy to browse, connect, and expand over time.

## Structure

- `00_CREATOR_BIBLE/` - explains the project itself: vision, standards, naming, and roadmap
- `01_WORLD_FOUNDATION/` - defines the rules of reality, cosmology, and core setting logic
- `02_NATURE/` - covers geography, ecosystems, climate, flora, fauna, and the physical environment
- `03_CIVILIZATION/` - covers governments, cities, trade, institutions, and infrastructure
- `04_CULTURE/` - covers language, customs, religion, identity, and daily life
- `05_HISTORY/` - covers eras, timelines, turning points, and major events
- `06_CHARACTERS/` - covers major people, factions, relationships, and character notes
- `07_STORY/` - covers plot arcs, scenes, drafts, and story planning
- `08_ART_BIBLE/` - covers the visual language, reference style, and art direction
- `09_GAME_DESIGN/` - covers systems, mechanics, and interactive design notes
- `10_REFERENCE/` - covers glossary entries, source notes, and supporting references

## How to use in Obsidian

1. Open the nested `VAYRANIS` folder as your vault.
2. Add notes inside the numbered folders instead of the vault root.
3. Link notes with standard Obsidian wiki links like `[[PROJECT_VISION]]` or `[[ROADMAP]]`.
4. Keep `INDEX.md` updated as the project grows so navigation stays simple.
5. Use one note per topic when possible so each file stays focused and easy to read.
