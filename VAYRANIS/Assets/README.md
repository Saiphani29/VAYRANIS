# Assets

This folder stores visual files for the VAYRANIS vault.

## Images

- `VAYRANIS-Cover.png` - wide vault cover for the project overview
- `VAYRANIS-Sigil.png` - emblem-style symbol for notes and references
- `World-of-VAYRANIS-Map.png` - the main world map reference for the setting
- `VAYRANIS-Logo.png` - the main logo reference for the project

## Use

Embed these images in Obsidian with `![[Assets/VAYRANIS-Cover.png]]` or `![[Assets/VAYRANIS-Sigil.png]]`.
