# VAYRANIS

The official World Bible, Creator Bible, Art Bible, and Story Bible of VAYRANIS.

This repository is set up to work as an Obsidian vault, so each folder can hold linked Markdown notes.

## Structure

- `00_CREATOR_BIBLE/` - project vision, standards, and roadmap
- `01_WORLD_FOUNDATION/` - core setting rules and cosmology
- `02_NATURE/` - geography, ecosystems, climate, and creatures
- `03_CIVILIZATION/` - governments, cities, trade, and institutions
- `04_CULTURE/` - language, customs, religion, and daily life
- `05_HISTORY/` - timelines, eras, and major events
- `06_CHARACTERS/` - important people, factions, and relationships
- `07_STORY/` - plot arcs, arcs, scenes, and story references
- `08_ART_BIBLE/` - visual identity, references, and art direction
- `09_GAME_DESIGN/` - mechanics, systems, and interactive design notes
- `10_REFERENCE/` - glossary, source notes, and external references

## How to use in Obsidian

1. Open this repository folder as your vault.
2. Add notes inside the numbered folders.
3. Link notes with standard Obsidian wiki links like `[[PROJECT_VISION]]`.
4. Keep `INDEX.md` updated as the project grows.
